# Step Central — Online Footwear Retail Store

ITCP318 Integrative Programming and Technology project — MERN e-commerce for footwear.

## Stack
- **Backend:** Express 5, MongoDB (Atlas), Mongoose, JWT (cookie) auth, Cloudinary, nodemailer, pdfkit, bad-words
- **Frontend:** React 19 + Vite, Redux + thunk, React Router 7, MUI, react-bootstrap, Formik + YUP, Firebase Auth, recharts

## Categories
Running · Basketball · Lifestyle

## Run
```bash
# backend (port 4001) — fill backend/.env first
cd backend
npm install
npm run dev

# frontend (port 5173)
cd frontend
npm install
npm run dev
```
